# 🧠 NeuroAdapt: Personalized Learning for Neurodivergent Students

### Empowering ADHD & Dyslexic Learners Through Adaptive, AI-Powered Education

---

## 🎯 Project Goal

**NeuroAdapt** is a dynamic, AI-powered web platform designed to support neurodivergent students—specifically those with ADHD and dyslexia—by personalizing their learning experience. Through adaptive text formatting, focus-enhancing tools, and gamified engagement, NeuroAdapt aims to improve educational outcomes and promote inclusive learning.

---

## 🚀 Key Features

### ✍️ Adaptive Text Formatting 
- ✅ Dyslexia-friendly fonts (e.g., OpenDyslexic)
- ✅ Adjustable font size, line spacing, and background color
- ✅ Reading modes: dark mode, distraction-free mode

### 🤖 AI-Powered Focus Support
- ⏱ Pomodoro-style study/break intervals
- 🔔 Visual/auditory reminders for attention checks
- 💬 GPT-based assistant for focus encouragement

### 🕹️ Gamification
- 🏅 Points for completed modules
- 🎯 Unlockable badges and streak counters
- 🗂 Optional leaderboard

### 👤 Personalization Dashboard
- 📈 Analytics on learning sessions, focus, and progress
- 🎨 Custom UI themes tailored to neurodivergent needs
- 💾 Preferences stored via local storage or Firebase

### 🧑‍🏫 Teacher/Admin Panel
- 📊 Overview of student usage and progress
- 🎛 Ability to set or suggest custom configurations
- 📝 Exportable reports (CSV or dashboard view)

## 🛠 Beginner-Friendly Development Phases

### Phase 1: Research & Planning
- Research ADHD/dyslexia-friendly UX
- Define user personas and learning pain points

### Phase 2: Frontend Setup
- Set up React project
- Pages: Home, Login/Signup, Dashboard, Settings

### Phase 3: Prototype UI
- Toggle settings for:
  - Font type (OpenDyslexic)
  - Background color
  - Font size and spacing

### Phase 4: Basic AI Integration
- Integrate GPT API to:
  - Suggest breaks
  - Encourage focus

### Phase 5: Gamification
- Implement:
  - Local storage point tracking
  - Basic badge unlock system

### Phase 6: User Personalization
- Build dashboard to store/retrieve:
  - Preferences
  - Progress stats
  - Streaks/badges

### Phase 7: Final Polish
- Accessibility testing (screen reader, keyboard nav)
- Mobile responsiveness
- MVP deployment on Vercel
